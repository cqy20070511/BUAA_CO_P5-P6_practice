# P5 往年题

整理版，2026-11-20。Q01—Q29 是历史资料改编；M01—M10 对应旧模拟题 Q01—Q10，X01 对应旧 BLZTAL。每题 24 点。

题号在整合仓库中须加 P5 前缀，例如 P5-Q01 和 P5-M01。所有编码都是本册练习协议，不宣称是历史原编码。本包使用的基础指令为 add、sub、ori、lui、lw、sw、beq、jal、jr、nop；PC 从 0x3000 开始，IM 4096 字、DM 3072 字，GRF 和 DM 复位清零。

顶层为 mips(clk, reset)，IM、DM 在 CPU 内部。GRF 和 DM 按课程要求打印带 PC 的写入日志。GRF 表示通用寄存器，DM 用整字编号，PC 是当前指令地址；操作栏为行为定义，不限制具体流水级。所有源使用写入前的旧值，写 $0 丢弃，固定宽度结果保留低位。

控制指令的 PC 赋值表示处理延迟槽后的地址；是否清空延迟槽以中文描述为准。槽内不安排控制指令。字节按小端选择，普通字访问对齐到四字节，半字对齐到两字节，测试地址均有效。

编码按高位到低位排列。R 型字段宽度依次为 6、5、5、5、5、6 位；I 型为 6、5、5、16 位。base 占 rs 字段。

## P5-Q01　cco

编码：`000000 rs rt rd 00000 110000`。

格式：`cco rd, rs, rt`。

描述：统计 rs 与 rt 按位与后结果中 1 的个数，零扩展写入 rd。

操作：

```verilog
integer i;
reg [31:0] count;
reg [31:0] data;
data = GRF[rs] & GRF[rt];
count = 0;
for (i = 0; i < 32; i = i + 1) count = count + data[i];
GRF[rd] <= count;
```

其他：按公共说明执行。 题源：S01，见来源索引。

## P5-Q02　bgezall

编码：`110000 rs 00000 offset16`。

格式：`bgezall rs, offset`。

描述：总是链接到 $31。rs 按有符号数解释大于等于零时执行延迟槽并相对跳转；否则清空延迟槽，从本条地址加 8 继续。

操作：

```verilog
GRF[31] <= PC + 32'd8;
if ($signed(GRF[rs]) >= 0) PC <= PC + 32'd4 + ({{16{offset[15]}}, offset} << 2);
else PC <= PC + 32'd8;
```

其他：按公共说明执行。 题源：S01，见来源索引。

## P5-Q03　lwso

编码：`110001 base 11111 offset16`。

格式：`lwso offset(base)`。

描述：读出整字，与旧 $31 按有符号数求和。没有有符号溢出时写回 $31；溢出时取消本条写回。

操作：

```verilog
reg signed [32:0] sum;
reg [31:0] address, word;
address = GRF[base] + {{16{offset[15]}}, offset};
word = DM[address[31:2]];
sum = $signed({GRF[31][31], GRF[31]}) + $signed({word[31], word});
if (sum[32] == sum[31]) GRF[31] <= sum[31:0];
```

其他：编码的 rt 固定为 11111；读取旧 $31。 题源：S01，见来源索引。

## P5-Q04　cmco

编码：`000000 rs 00000 rd 00000 110001`。

格式：`cmco rd, rs`。

描述：找出 rs 中最长的一段连续的 1，段长写入 rd，不连接最高位与最低位。

操作：

```verilog
integer i;
reg [31:0] run_length, best;
run_length = 0; best = 0;
for (i = 31; i >= 0; i = i - 1) begin
    if (GRF[rs][i]) run_length = run_length + 1;
    else run_length = 0;
    if (run_length > best) best = run_length;
end
GRF[rd] <= best;
```

其他：按公共说明执行。 题源：S01、S02，见来源索引。

## P5-Q05　blezalc

编码：`110010 rs 00000 offset16`。

格式：`blezalc rs, offset`。

描述：rs 按有符号数解释小于等于零时，相对跳转并链接到 $31；否则不链接。两条路径都执行延迟槽。

操作：

```verilog
if ($signed(GRF[rs]) <= 0) begin
    GRF[31] <= PC + 32'd8;
    PC <= PC + 32'd4 + ({{16{offset[15]}}, offset} << 2);
end else PC <= PC + 32'd8;
```

其他：失败路径在历史回忆间有差异，本练习固定延迟槽总执行。 题源：S01、S02，见来源索引。

## P5-Q06　lrm

编码：`110011 base rt offset16`。

格式：`lrm rt, offset(base)`。

描述：读出整字，最低五位作为目的寄存器编号，把旧 rt 的值写入该寄存器。

操作：

```verilog
reg [31:0] address, word;
address = GRF[base] + {{16{offset[15]}}, offset};
word = DM[address[31:2]];
GRF[word[4:0]] <= GRF[rt];
```

其他：本题采用 2020 记载中“读数低位决定目标”的版本。 题源：S01、S02，见来源索引。

## P5-Q07　swc

编码：`000000 rs rt rd 00000 110010`。

格式：`swc rd, rs, rt`。

描述：rt 为奇数时将 rs 循环左移，为偶数时循环右移。移位量只取 rt 最低五位，结果写 rd。

操作：

```verilog
reg [4:0] amount;
reg [31:0] result;
amount = GRF[rt][4:0];
if (amount == 0) result = GRF[rs];
else if (GRF[rt][0]) result = (GRF[rs] << amount) | (GRF[rs] >> (32-amount));
else result = (GRF[rs] >> amount) | (GRF[rs] << (32-amount));
GRF[rd] <= result;
```

其他：采用 S03/S05 的寄存器奇偶版本。 题源：S03、S04、S05，见来源索引。

## P5-Q08　bonall

编码：`110100 rs rt offset16`。

格式：`bonall rs, rt, offset`。

描述：总是链接到 $31。两个有符号输入的数学和为零时，执行延迟槽并相对跳转；否则清槽并顺序继续。

操作：

```verilog
reg signed [32:0] sum;
sum = $signed({GRF[rs][31], GRF[rs]}) + $signed({GRF[rt][31], GRF[rt]});
GRF[31] <= PC + 32'd8;
if (sum == 0) PC <= PC + 32'd4 + ({{16{offset[15]}}, offset} << 2);
else PC <= PC + 32'd8;
```

其他：判断数学相反数；两个 0x80000000 不满足条件。 题源：S03、S04、S05，见来源索引。

## P5-Q09　lhogez

编码：`110101 base rt offset16`。

格式：`lhogez rt, offset(base)`。

描述：读取半字，1 的个数严格大于 8 时零扩展写入 rt；否则向 $31 写入本条指令地址加 4。

操作：

```verilog
reg [31:0] address, word;
reg [15:0] halfword;
integer i, count;
address = GRF[base] + {{16{offset[15]}}, offset};
word = DM[address[31:2]];
halfword = address[1] ? word[31:16] : word[15:0];
count = 0;
for (i = 0; i < 16; i = i + 1) count = count + halfword[i];
if (count > 8) GRF[rt] <= {16'b0, halfword};
else GRF[31] <= PC + 32'd4;
```

其他：测试地址为偶数，保留原记载的零扩展与 PC+4。 题源：S03、S04，见来源索引。

## P5-Q10　bltzalx

编码：`110110 rs rt offset16`。

格式：`bltzalx rs, rt, offset`。

描述：总是链接并执行延迟槽。rs 为负数时，将有符号偏移加上 2 的 k 次幂，再乘 4，作为相对 PC+4 的位移；k 取 rt 的最低两位。否则顺序继续。

操作：

```verilog
reg [31:0] displacement;
displacement = ({{16{offset[15]}}, offset} + (32'd1 << GRF[rt][1:0])) << 2;
GRF[31] <= PC + 32'd8;
if ($signed(GRF[rs]) < 0) PC <= PC + 32'd4 + displacement;
else PC <= PC + 32'd8;
```

其他：历史称 bltzal，本册加 x 区分标准同名指令。 题源：S03，见来源索引。

## P5-Q11　addei

编码：`110111 rs rt imm16`。

格式：`addei rt, rs, imm`。

描述：立即数高 16 位固定补 1，与 rs 作有符号加法。没有有符号溢出则写和的低 32 位；有溢出则写扩展后的立即数。

操作：

```verilog
reg [31:0] extended;
reg signed [32:0] sum;
extended = {16'hffff, imm};
sum = $signed({GRF[rs][31], GRF[rs]}) + $signed({1'b1, extended});
if (sum[32] == sum[31]) GRF[rt] <= sum[31:0];
else GRF[rt] <= extended;
```

其他：按公共说明执行。 题源：S03、S14，见来源索引。

## P5-Q12　lbget

编码：`111000 base rt offset16`。

格式：`lbget rt, offset(base)`。

描述：读出有效地址处字节并符号扩展。字节为负时写 base，否则写 rt。

操作：

```verilog
reg [31:0] address, word;
reg [7:0] data_byte;
address = GRF[base] + {{16{offset[15]}}, offset};
word = DM[address[31:2]];
data_byte = word >> (address[1:0] * 8);
if (data_byte[7]) GRF[base] <= {{24{data_byte[7]}}, data_byte};
else GRF[rt] <= {24'b0, data_byte};
```

其他：按公共说明执行。 题源：S03、S06，见来源索引。

## P5-Q13　fz

编码：`000000 rs rt rd 00000 110011`。

格式：`fz rd, rs, rt`。

描述：从 rs 最低位向高位查找 0，依次改成 1，最多修改无符号 rt 指定的数量，结果写 rd。

操作：

```verilog
reg [31:0] result, remaining;
integer i;
result = GRF[rs]; remaining = GRF[rt];
for (i = 0; i < 32; i = i + 1)
    if (!result[i] && remaining != 0) begin
        result[i] = 1; remaining = remaining - 1;
    end
GRF[rd] <= result;
```

其他：rt 使用完整 32 位，数量不足时把所有零位都置 1。 题源：S07，见来源索引。

## P5-Q14　bsveall

编码：`111001 rs rt offset16`。

格式：`bsveall rs, rt, offset`。

描述：按有符号数选两个输入的较小值。较小值为偶数时执行槽并相对跳转，否则清槽顺序继续；两种情况都链接。

操作：

```verilog
reg [31:0] smaller;
smaller = $signed(GRF[rs]) < $signed(GRF[rt]) ? GRF[rs] : GRF[rt];
GRF[31] <= PC + 32'd8;
if (!smaller[0]) PC <= PC + 32'd4 + ({{16{offset[15]}}, offset} << 2);
else PC <= PC + 32'd8;
```

其他：按公共说明执行。 题源：S07，见来源索引。

```verilog
GRF[rd] <= GRF[rs] ^ (GRF[rt] & 32'h55555555);
```

## P5-Q17　jtl

编码：`111011 rs rt offset16`。

格式：`jtl rs, rt, offset`。

描述：计算普通相对分支地址和两个寄存器的 32 位和，按无符号地址比较。分支地址严格更小时执行槽并跳到它；否则清槽并跳到寄存器和。总是链接。

操作：

```verilog
reg [31:0] relative, register_sum;
relative = PC + 32'd4 + ({{16{offset[15]}}, offset} << 2);
register_sum = GRF[rs] + GRF[rt];
GRF[31] <= PC + 32'd8;
if (relative < register_sum) PC <= relative;
else PC <= register_sum;
```

其他：地址比较的无符号性和相等处理为练习明确化。 题源：S08、S09，见来源索引。

## P5-Q18　lwoc

编码：`111100 base rt offset16`。

格式：`lwoc rt, offset(base)`。

描述：偏移符号扩展后左移两位再加基址，读取整字。读数最高位为零时写到读数最低四位指定的寄存器，否则写到 rt。

操作：

```verilog
reg [31:0] address, word;
address = GRF[base] + ({{16{offset[15]}}, offset} << 2);
word = DM[address[31:2]];
if (!word[31]) GRF[word[3:0]] <= word;
else GRF[rt] <= word;
```

其他：偏移只左移两位一次；不读取旧 rt。 题源：S08、S09、S10，见来源索引。

## P5-Q19　addoi

编码：`111101 rs rt imm16`。

格式：`addoi rt, rs, imm`。

描述：rs 加符号扩展的立即数，先保留低 32 位，再将这个补码和取相反数，并转换成 32 位原码：最高位表示负号，低 31 位表示绝对值。

操作：

```verilog
reg [31:0] sum, negated, magnitude;
sum = GRF[rs] + {{16{imm[15]}}, imm};
negated = -sum;
magnitude = negated[31] ? -negated : negated;
GRF[rt] <= {negated[31], magnitude[30:0]};
```

其他：测试避开和为 0x80000000 的情况；零写为 0。位宽和极值限制为练习补充。 题源：S11、S06，见来源索引。

## P5-Q20　ccc

编码：`000000 rs rt rd 00000 110101`。

格式：`ccc rd, rs, rt`。

描述：比较 rs 的前导零数与 rt 的前导一数。前者严格更大时，结果用 rs 高半字、rt 低半字；否则交换半字来源。

操作：

```verilog
integer i;
integer zeros, ones;
reg stop_rs, stop_rt;
zeros = 0; ones = 0; stop_rs = 0; stop_rt = 0;
for (i = 31; i >= 0; i = i - 1) begin
    if (!stop_rs && !GRF[rs][i]) zeros = zeros + 1; else stop_rs = 1;
    if (!stop_rt && GRF[rt][i]) ones = ones + 1; else stop_rt = 1;
end
if (zeros > ones) GRF[rd] <= {GRF[rs][31:16], GRF[rt][15:0]};
else GRF[rd] <= {GRF[rt][31:16], GRF[rs][15:0]};
```

其他：按公共说明执行。 题源：S13，见来源索引。

## P5-Q21　cjoc

编码：`111110 rs rt offset16`。

格式：`cjoc rs, rt, offset`。

描述：以 offset 最低三位为起始位号，从 rs 中取向高位的 8 位无符号窗口。窗口大于 21 时向 rt 链接并执行槽、相对跳转；否则不链接且清槽。

操作：

```verilog
reg [7:0] window;
window = GRF[rs] >> offset[2:0];
if (window > 8'd21) begin
    GRF[rt] <= PC + 32'd8;
    PC <= PC + 32'd4 + ({{16{offset[15]}}, offset} << 2);
end else PC <= PC + 32'd8;
```

其他：rt 是链接目的，不读取其旧值。失败同时取消链接与槽。 题源：S13，见来源索引。

## P5-Q22　ccs

编码：`111111 base rt offset16`。

格式：`ccs rt, offset(base)`。

描述：统计读出字高、低半字中 1 的个数。高半字计数更大时目的为 31，否则目的为高半字计数。写入值为读数与旧 rt 的异或。

操作：

```verilog
reg [31:0] address, word;
integer i, high_count, low_count, destination;
address = GRF[base] + {{16{offset[15]}}, offset};
word = DM[address[31:2]]; high_count = 0; low_count = 0;
for (i = 0; i < 16; i = i + 1) begin
    high_count = high_count + word[i+16]; low_count = low_count + word[i];
end
destination = high_count > low_count ? 31 : high_count;
GRF[destination] <= word ^ GRF[rt];
```

其他：按公共说明执行。 题源：S13，见来源索引。

## P5-Q23　dsc

编码：`010000 rs rt imm16`。

格式：`dsc rs, rt, imm`。

描述：只读取 rt。将它左移 imm 的最高五位指定的位数，再与它算术右移 imm 最低五位的结果异或，写入 rs。

操作：

```verilog
reg signed [31:0] arithmetic_result;
arithmetic_result = $signed(GRF[rt]) >>> imm[4:0];
GRF[rs] <= (GRF[rt] << imm[15:11]) ^ arithmetic_result;
```

其他：中间 imm[10:5] 不参与运算，算术右移先单独求值。 题源：S13，见来源索引。

## P5-Q24　bloc

编码：`010001 rs rt offset16`。

格式：`bloc rs, rt, offset`。

描述：rs 的前导一数严格大于 rt 最低六位时相对跳转，否则顺序继续。两条路径均链接到 $31 并执行槽。

操作：

```verilog
integer i;
reg [31:0] count;
reg found;
reg [31:0] data;
data = GRF[rs]; count = 0; found = 0;
for (i = 31; i >= 0; i = i - 1) begin
    if (!found && data[i] == 1'b1) count = count + 1;
    else found = 1;
end
GRF[31] <= PC + 32'd8;
if (count > GRF[rt][5:0]) PC <= PC + 32'd4 + ({{16{offset[15]}}, offset} << 2);
else PC <= PC + 32'd8;
```

其他：按公共说明执行。 题源：S13，见来源索引。

## P5-Q25　lhp

编码：`010010 base rt offset16`。

格式：`lhp rt, offset(base)`。

描述：以字偏移读出整字，与旧 rt 异或。异或结果高低半字相同时，目的为最高 1 的位号；否则目的为 31。写入原始读数。

操作：

```verilog
reg [31:0] address, word, mixed;
integer i, destination;
address = GRF[base] + ({{16{offset[15]}}, offset} << 2);
word = DM[address[31:2]]; mixed = word ^ GRF[rt]; destination = 0;
if (mixed[31:16] == mixed[15:0]) begin
    for (i = 0; i < 32; i = i + 1) if (mixed[i]) destination = i;
end else destination = 31;
GRF[destination] <= word;
```

其他：异或结果为零时目的为 0。 题源：S13，见来源索引。

## P5-Q29　lweo

编码：`010110 base rt offset16`。

格式：`lweo rt, offset(base)`。

描述：读出整字，偶数写 rt，奇数写 $31；实际写回值始终是原始读数。

操作：

```verilog
reg [31:0] address, word;
address = GRF[base] + {{16{offset[15]}}, offset};
word = DM[address[31:2]];
if (word[0]) GRF[31] <= word;
else GRF[rt] <= word;
```

其他：助记符为本册练习命名，原记录年份未确认。 题源：S14，见来源索引。
