# P5 模拟题（沿用原 10 题）

整理版，2026-11-20。Q01—Q29 是历史资料改编；M01—M10 对应旧模拟题 Q01—Q10，X01 对应旧 BLZTAL。每题 24 点。

题号在整合仓库中须加 P5 前缀，例如 P5-Q01 和 P5-M01。所有编码都是本册练习协议，不宣称是历史原编码。本包使用的基础指令为 add、sub、ori、lui、lw、sw、beq、jal、jr、nop；PC 从 0x3000 开始，IM 4096 字、DM 3072 字，GRF 和 DM 复位清零。

顶层为 mips(clk, reset)，IM、DM 在 CPU 内部。GRF 和 DM 按课程要求打印带 PC 的写入日志。GRF 表示通用寄存器，DM 用整字编号，PC 是当前指令地址；操作栏为行为定义，不限制具体流水级。所有源使用写入前的旧值，写 $0 丢弃，固定宽度结果保留低位。

控制指令的 PC 赋值表示处理延迟槽后的地址；是否清空延迟槽以中文描述为准。槽内不安排控制指令。字节按小端选择，普通字访问对齐到四字节，半字对齐到两字节，测试地址均有效。

编码按高位到低位排列。R 型字段宽度依次为 6、5、5、5、5、6 位；I 型为 6、5、5、16 位。base 占 rs 字段。

## P5-M01　pcxor

编码：`000000 rs rt rd 00000 111000`。

格式：`pcxor rd, rs, rt`。

描述：统计两个输入异或后 1 的个数，写 rd。

操作：

```verilog
integer i;
reg [31:0] count;
reg [31:0] data;
data = GRF[rs] ^ GRF[rt];
count = 0;
for (i = 0; i < 32; i = i + 1) count = count + data[i];
GRF[rd] <= count;
```

其他：原模拟题 Q01，编码和测试点不变。

## P5-M02　bwin

编码：`000000 rs rt rd 00000 111001`。

格式：`bwin rd, rs, rt`。

描述：以 rt 最低五位作为起始位号，从 rs 逻辑右移后取低字节，符号扩展写 rd。超过最高位的位置补零。

操作：

```verilog
reg [31:0] shifted;
shifted = GRF[rs] >> GRF[rt][4:0];
GRF[rd] <= {{24{shifted[7]}}, shifted[7:0]};
```

其他：原模拟题 Q02。

## P5-M03　sathi

编码：`110000 rs rt imm16`。

格式：`sathi rt, rs, imm`。

描述：rs 加符号扩展立即数。有符号数学和超范围时写该方向的边界，否则写和。

操作：

```verilog
reg signed [32:0] sum;
sum = $signed({GRF[rs][31], GRF[rs]}) + $signed({{17{imm[15]}}, imm});
if (sum > 33'sd2147483647) GRF[rt] <= 32'h7fffffff;
else if (sum < -33'sd2147483648) GRF[rt] <= 32'h80000000;
else GRF[rt] <= sum[31:0];
```

其他：原模拟题 Q03。

## P5-M04　bopz

编码：`110001 rs rt offset16`。

格式：`bopz rs, rt, offset`。

描述：有符号数学和严格小于零时执行槽并相对跳转，否则清槽顺序继续。不写寄存器。

操作：

```verilog
reg signed [32:0] sum;
sum = $signed({GRF[rs][31], GRF[rs]}) + $signed({GRF[rt][31], GRF[rt]});
if (sum < 0) PC <= PC + 32'd4 + ({{16{offset[15]}}, offset} << 2);
else PC <= PC + 32'd8;
```

其他：原模拟题 Q04。

## P5-M05　bmeqal

编码：`110010 rs rt offset16`。

格式：`bmeqal rs, rt, offset`。

描述：比较两个输入低半字的无符号值。rs 小于等于 rt 时相对跳转并链接，否则不链接。槽总执行。

操作：

```verilog
if (GRF[rs][15:0] <= GRF[rt][15:0]) begin
    GRF[31] <= PC + 32'd8;
    PC <= PC + 32'd4 + ({{16{offset[15]}}, offset} << 2);
end else PC <= PC + 32'd8;
```

其他：原模拟题 Q05。

## P5-M06　joddal

编码：`110011 rs rt offset16`。

格式：`joddal rs, rt, offset`。

描述：总是链接。rs 为奇数时执行槽并相对跳转；为偶数时清槽，跳到旧 rt 加 rs 的 bit3、bit2 对应地址增量。

操作：

```verilog
GRF[31] <= PC + 32'd8;
if (GRF[rs][0]) PC <= PC + 32'd4 + ({{16{offset[15]}}, offset} << 2);
else PC <= GRF[rt] + (GRF[rs] & 32'h0000000c);
```

其他：原模拟题 Q06。

## P5-M07　lwnz

编码：`110100 base rt offset16`。

格式：`lwnz rt, offset(base)`。

描述：整字读数非零才写 rt，为零保留旧值。

操作：

```verilog
reg [31:0] address, word;
address = GRF[base] + {{16{offset[15]}}, offset};
word = DM[address[31:2]];
if (word != 0) GRF[rt] <= word;
```

其他：原模拟题 Q07。

## P5-M08　lbsel

编码：`110101 base rt offset16`。

格式：`lbsel rt, offset(base)`。

描述：字节符号扩展，负数写 base，否则写 rt。

操作：

```verilog
reg [31:0] address, word;
reg [7:0] data_byte;
address = GRF[base] + {{16{offset[15]}}, offset};
word = DM[address[31:2]];
data_byte = word >> (address[1:0] * 8);
if (data_byte[7]) GRF[base] <= {{24{data_byte[7]}}, data_byte};
else GRF[rt] <= {24'b0, data_byte};
```

其他：原模拟题 Q08。

## P5-M09　lwgate

编码：`110110 base rt offset16`。

格式：`lwgate rt, offset(base)`。

描述：整字读数与旧 rt 作有符号加法。仅当不溢出且数学和为奇数时，将和写入 rt。

操作：

```verilog
reg signed [32:0] sum;
reg [31:0] address, word;
address = GRF[base] + {{16{offset[15]}}, offset};
word = DM[address[31:2]];
sum = $signed({word[31], word}) + $signed({GRF[rt][31], GRF[rt]});
if (sum[32] == sum[31] && sum[0]) GRF[rt] <= sum[31:0];
```

其他：原模拟题 Q09。

## P5-M10　lwxsel

编码：`110111 base rt offset16`。

格式：`lwxsel rt, offset(base)`。

描述：以字偏移读数，与旧 rt 异或。异或最高位为 1 时目的为 rt，否则为异或低四位。实际写回原始读数。

操作：

```verilog
reg [31:0] address, word, mixed;
address = GRF[base] + ({{16{offset[15]}}, offset} << 2);
word = DM[address[31:2]]; mixed = word ^ GRF[rt];
if (mixed[31]) GRF[rt] <= word;
else GRF[mixed[3:0]] <= word;
```

其他：原模拟题 Q10。
